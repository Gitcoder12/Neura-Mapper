# Contributing to Neura-Mapper

1. Read README.md and FEATURE_UPGRADE_PLAN.md.
2. Select one bounded grid/pathfinding task.
3. Work on a feature branch and add deterministic test grids.
4. Test invalid dimensions, coordinates, blocked paths and unreachable targets.
5. Document path costs, connectivity and assumptions.
6. Keep examples synthetic and non-clinical.
7. Open a PR with exact tests and limitations.

Do not add clinical-use claims, patient data or medical-image handling without an approved scope and appropriate validation/regulatory review. Human maintainers approve merges.
